# 소재 리사이저 (asset-resizer)

마스터 시안(이미지·영상)을 올리면 매체별 규격으로 리사이즈하고, 캠페인명·소재명·매체명·해상도·버전을 넣은 파일명으로 내려받게 해 주는 웹 도구입니다.

- 웹에서 바로 사용: https://streetcow.github.io/asset-resizer/
- 모든 처리는 **내 브라우저 안에서만** 이루어지며, 올린 파일은 서버로 전송되지 않습니다.
- 화면 맨 위 **▶ 테스트하기** 버튼을 누르면 가상 데이터로 바로 체험할 수 있습니다.
- 권장 환경: 최신 Chrome / Edge (영상 변환은 이 브라우저의 영상 인코딩 기능을 사용합니다).
- 단일 파일 `index.html` 하나로 동작하므로 내려받아 더블클릭으로도 실행할 수 있습니다.

## 알려진 한계
- TIF 파일은 아직 지원하지 않습니다.
- 영상 변환 시간은 영상 길이와 비슷합니다.
